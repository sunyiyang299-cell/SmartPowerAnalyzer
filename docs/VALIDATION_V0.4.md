## 算法、单位和来源

电压 < 用户下限为偏低；电压 > 用户上限为偏高；电流 > 用户上限为偏高。等号不触发事件。阈值须为有限非负数，下限 < 上限，电流上限 > 0；用户输入不静默截断或修正。
同一原始行可生成多个事件。事件总数与按原始行去重的采样点数分别统计；类型次数分别统计。事件包含数据集 ID、0 起始原始位置、时间、参数、数值、类型、触发阈值、单位和来源。

P=U×I×PF（W），S=U×I（VA），|Q|=S×sqrt(max(0,(1−PF)×(1+PF)))（var）。仅单相正弦稳态交流；U/I 为有效值。|Q| 不推断感容性或超前滞后。
模拟来源从数据对象一直传至事件、图表和 PNG。图片可见“模拟数据，非真实设备测量”，另有 Unicode PNG 文本来源元信息；元信息关键字采用 PNG 兼容的拉丁字符 Dataset/Source。

界面声明：异常检测结果仅供数据分析参考，不构成设备安全或电气标准符合性认证。
没有异常只显示“未检测到符合当前阈值条件的异常记录。”

## 时间与一致性策略

- 原始保存顺序不变。曲线采用稳定时间排序，重复时间全部保留，重复点按原始先后连接，不聚合删除样本。
- 原始时间拆为整数秒及纳秒内余数，再生成相对秒坐标；不通过整段 datetime64[ns] 强制转换，公元 3000 年不会绕回错误日期。纳秒间隔与跨日期均有断言。
- 读数和异常保留原始时间与索引，图表刻度显示日期及秒/毫秒；极大时间跨度受 float64 坐标分辨率限制。
- 联动核对数据集 ID、名称、来源、完整时间及三电气字段 SHA-256 指纹。阈值/启用/检测数据集变化发出失效信号，清除全部旧标记。
- 分析数据集切换或失败立即清空曲线。任务捕获修订号，配置变化后丢弃晚到结果。
- PNG 对话框返回后再检查修订号；切换数据集取消导出。抓取和写入之间不处理新 GUI 事件，因此同一张图像不会混合两个数据集。
- 同目录临时 PNG 写完后原子改名/替换；覆盖必须用户确认，拒绝覆盖和写入失败保留原文件。

## 性能实现与实际测量

曲线使用 NumPy、1 像素笔、关闭抗锯齿、clipToView 和 peak 自动降采样。原始数组保持完整，只改变显示数据。异常检测遍历完整校验数据，不使用降采样曲线。
每类当前视区最多 1500 个代表标记，一个类别只用一个 ScatterPlotItem；缩放后重新选择。全部事件始终在明细中，图上明确说明代表标记限制，不以标记数代替事件数。

数据量为 100000 条模拟采样；故意使用电压上限 1 V、电流上限 0.1 A 产生 200000 个事件、100000 个唯一异常采样点，验证高密度情况。检测/分析在后台，图表绑定、首次绘制与交互在 GUI 线程。计时仅代表当前机器的一次运行，不是跨硬件性能承诺。

最终本地 offscreen 全量测试测得：后台分析+检测到后续交互总计 **1.0482 s**；绑定与首次抓图 **102.37 ms**；5 ms 定时器实际触发 **38 次**，最大相邻触发间隔 **102.72 ms**。界面有约十分之一秒的绘制停顿，无长期冻结；测试还执行 3 次缩放和平移。时间包含 Python/Qt 事件调度，不是硬实时采样保证。

原生 windows 后端最终对应测量：总计 **1.2194 s**，绑定及首次抓图 **124.67 ms**，定时器 **88 次**，最大相邻间隔 **124.87 ms**。

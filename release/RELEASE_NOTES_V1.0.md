# 智电析 V1.0.0 Windows 发行候选说明

正式名称：智电析电力系统运行数据分析与可视化软件 V1.0。

本交付为待用户审核的1.0.0候选包，未创建正式Release、标签或数字签名；不代表已完成独立干净机和全部发行许可验收。

## 本次变更

- 版本与窗口、设置、PDF/Excel、EXE属性一致更新为1.0.0。
- 保留V0.1～V0.9全部业务功能与测试。
- PDF完整异常明细按256事件延迟构造，降低大报告的内存与排版开销，不截断数据；当前仍不可取消。
- 原创SVG/多尺寸ICO；资源定位与当前目录分离。
- 可维护PyInstaller onedir、当前用户Inno安装器、完整便携ZIP、真实校验值和Windows构建验证工作流。
- 构建隔离DLL搜索路径，避免开发工具的ICU/UCRT污染；窗口显示在事件循环启动后调度。
- 缩短许可文件路径并记录原始来源，避免可消除的便携解压深层路径；关闭验证重新确认窗口句柄，仅重试失效句柄。
- 提供手册、设计、测试、验证、依赖许可审查及软著候选材料。

## 真实验证

Windows11 x64/Python3.13.0。源码offscreen与原生Qt各321项测试、24子测试通过；实际冻结EXE在独立中文目录/独立工作目录、无Python/Git PATH下完成全部业务和重启读取。安装器完成当前用户安装、开始菜单启动、业务、卸载、数据逐字节保留、重装重读和最终卸载。

测试只用模拟数据与隔离数据库。禁用Python socket验证不等于物理断网。宿主机仍安装有Python，因此不是独立无Python干净机验收。
